# Istari

A dark, scholarly theme for Obsidian: warm ink, parchment text, restrained gold, Garamond type.

- `theme/`: the theme. Copy the folder to `.obsidian/themes/Istari/` in your vault.
- `companion-plugin/`: optional. Margin sidenotes from footnotes, `THEOREM`-style callout shorthand, and clean titles for untitled callouts. Copy to `.obsidian/plugins/istari-companion/` and enable it under Community plugins.
