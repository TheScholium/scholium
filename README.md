# The Scholium

*Notes from the margin of a physics degree.*

Open-source study tools from a math and physics undergraduate: page templates for e-ink notebooks, an Obsidian theme, and the code that builds them.

A *scholium* is the note that follows a proof — the remark in the margin that explains it. Spinoza's *Ethics* and Newton's *Principia* are full of them.

## The templates

| Template | Use |
|---|---|
| The Blurt | Recall a section from memory on graph paper, then list the gaps |
| The Time Trial | Budget time per question, then track five timed attempts |
| The Error Log | Each mistake, its type, and the correct move |
| The Research | Big-picture notes on a paper or talk beyond your current level |
| The Exam Plan | Topic checklist and a three-week countdown |
| The Class Hub | One page per course: professor, schedule, grades, exams, policies |
| The Study Week | Undated weekly schedule, 6 am to midnight |
| The Week | To-do list, weekly goal, habit rings, wins |
| The Month (28 / 30 / 31) | Nine habits across the days of a month |

Every page is undated and reusable.

### Install on a Supernote Nomad

1. Download the latest release (or the PNG files in `templates/nomad`).
2. Connect the Nomad by USB, or use the Supernote Partner app.
3. Copy the PNG files into the **MyStyle** folder.
4. Create a note and select the template from your custom templates.

The pages also fit the reMarkable 2, which has the same resolution.
